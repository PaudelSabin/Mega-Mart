# MegaMart Ecommerce Frontend

React + TypeScript + Vite recreation of the MegaMart Figma landing page.
Focus: reusable components and typed props (no mock data, no `.map()`).

## Stack
Vite, React, TypeScript. Styling: one CSS file per component, plus global tokens and reset in `src/index.css`.

## Install
```bash
npm install
```

## Run
```bash
npm run dev
```

## Build
```bash
npm run build
```
